# Dutch 2017 regression corpus

Tournaments generated by bbpPairings v5.0.1 (Apache-2.0), the Oracle for the Dutch System as in force until
2026-01-31 (the pre-2026 Swiss Rules Edition):

```sh
bbpPairings.exe --dutch -g <config> -o <file> -s <seed>
```

with 10–24 (`small-*`), 30–40 (`mid-*`) and 55–62 (`big-*`) players, a stress mix of 12–62 players with heavy
forfeits (`stress-*`), and long tournaments of 14–40 players over up to 30 rounds (`long-*`). Every round is bbp's
own pairing, so `DutchRegressionCorpusTest` re-pairs each round under `SwissRulesEdition.PRE_2026` and requires
the identical pairing, colours included.
