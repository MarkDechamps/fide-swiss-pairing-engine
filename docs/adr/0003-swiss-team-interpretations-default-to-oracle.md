# Swiss Team interpretations default to the oracle's reading

C.04.6 (2026) has three points where the text literally allows two readings that give different pairings: [C6] pass/fail vs graded, the Type B last-round CD-0 preference, and which score decides a floater under acceleration. No TEC ruling is sought, so each is a switchable Interpretation, and each defaults to Gacrux's reading, even where we find the other reading at least as strong (the probe refuted Gacrux's argument for pass/fail [C6]). The default is then verified exactly against the only Oracle. The alternative readings are still available but only witness-checked. The single exception is Gacrux's bracket-seat order (3.6.1), which is a bug, not a reading: there the library follows the text and records a Known Divergence.

## Considered Options

- Default to our own preferred reading: the defaults would then have no Oracle, and every default-profile tournament would be unverifiable.
- Fix one reading with no setting: this contradicts "configurable where the text allows both" (Contact FIDE Technical Commission).

## Consequences

Changing a default later changes pairings for existing users, so a TEC ruling that goes against a default needs a new Swiss Rules Edition or a documented breaking change.
